# WaveSpeed Homebrew Tap

```sh
brew tap wavespeedai/tap
brew install wavespeed
```

Installs the [WaveSpeed CLI](https://github.com/WaveSpeedAI/wavespeed-cli) — generate images, video, audio, and 3D from the terminal via [wavespeed.ai](https://wavespeed.ai).
